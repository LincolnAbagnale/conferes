# Conferes

Painel de conferência diária (lojas, relatórios, conversores) para usar em tela cheia no tablet ou no PC.

- Site: https://lincolnabagnale.github.io/conferes/
- Funciona offline (PWA). No Chrome do tablet: ⋮ → Adicionar à tela inicial.
- Sincronização entre aparelhos via Supabase: preencha `config.js` e rode `supabase.sql` uma vez.
